# RSVP Speed Reader

A modern browser-based **RSVP (Rapid Serial Visual Presentation) speed reader** that improves readability and comprehension using pivot-letter anchoring, smart timing, chunked word display, and optional comprehension quizzes.

This project is a single-file HTML app with no dependencies — just open it in a browser and start reading.

---

## 🚀 Features

### Core RSVP Engine
- Rapid Serial Visual Presentation (RSVP) word display
- Adjustable reading speed (WPM)
- Word chunking (1–3 words per frame)
- Real-time playback controls (start, pause, reset)
- Jump forward/backward by configurable word counts

### Visual Enhancements
- Pivot-letter highlighting (Spritz-style)
- Customizable pivot color and position
- Responsive typography and layout
- Minimalist dark UI optimized for focus

### Smart Timing System
- Automatic pauses at punctuation
- Longer pauses at paragraph breaks
- Slowdown for long or complex words
- Optional speed ramping (gradually increases WPM)

### Comprehension Mode
- Automatically generated fill-in-the-blank quizzes
- Multiple-choice questions
- Scoring and comprehension feedback
- Optional quiz trigger at the end of reading

### Keyboard Shortcuts
| Key | Action |
|-----|--------|
| Space | Play / Pause |
| ← / → | Jump backward / forward |
| ↑ / ↓ | Increase / decrease WPM |
| Q | Toggle quiz mode |
| R | Reset reader |
| Esc | Close quiz |

---

## 🧠 Why This Exists

Traditional RSVP tools maximize speed but often sacrifice comprehension.

This prototype explores a better balance by combining:

- visual anchoring (pivot letters),
- cognitive pacing (smart pauses),
- adaptive difficulty (speed ramping),
- and comprehension feedback (quizzes).

The goal is not just faster reading — but **faster understanding**.

## 🛠️ How to Use

### Option 1: Run Locally
1. Download the HTML file.
2. Open it in any modern browser.
3. Paste text and click **Start**.

### Option 2: Host on GitHub Pages
1. Create a GitHub repository.
2. Add the file as `index.html`.
3. Enable GitHub Pages in repo settings.
4. Open your live URL.
